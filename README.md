# 🎯 Pro Sens Converter & Aim Trainer

> A lightweight, ad-free, 1:1 mouse sensitivity converter and browser-based reflex trainer for competitive FPS games.

---

## 🚀 Live Demo
Experience the tool directly in your browser:  
👉 **[Launch Pro Sens Converter](https://prosensconverter.github.io/pro-sens-converter/)**

---

## ✨ Features

- **1:1 Engine Multiplier Conversion:** Accurately matches true angular yaw values across competitive shooter engines. Maintains consistent physical cm/360 rotation distance.
- **Built-in Web Aim Trainer:** 30-second reflex challenge tracking target accuracy, hit count, and reaction speed in milliseconds (ms).
- **Progressive Ranking:** Tier and ranking system calculated locally based on reaction latency.
- **Zero Framework Bloat:** 100% pure Vanilla HTML, CSS, and JavaScript. Instant page loads, zero trackers, and zero intrusive ads.
- **Works Offline:** Runs entirely client-side once loaded.
